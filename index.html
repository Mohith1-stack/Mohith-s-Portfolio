02

AEGIS

Detects CPU side-channel attacks such as Spectre, Flush+Reload and Prime+Probe in real time, then contains the attacking process at the hardware level.

Category
Hardware security
Status
Research
  • Python
  • PyTorch
  • eBPF
  • Linux PMU
  • Intel RDT
  • CNN
  • Bi-LSTM
GitHub↗ (opens in a new tab)

eBPF probes stream hardware performance counters (cache misses, branch mispredictions, context switches) into a deep learning model. When it flags an attack, the attacking process is moved into a restricted Intel RDT class of service, limited to one cache way and 10% memory bandwidth, so the side channel collapses without killing the process.

  • Three-part model: a CNN over cache occupancy, a Bi-LSTM over access timing and a dense network over system state, fused with cross-modal attention
  • 99.33% accuracy and 1.29 ms average inference per sample on its holdout test set
  • Falls back to software throttling on machines without Intel RDT or AMD QoS

03

TraceSieve

Records what a Python program actually executed and compares runs, exposing unexpected behaviour and code paths a test never touched.

Category
Runtime auditing tool
Status
Built
  • Python
  • sys.settrace
  • AST
  • SQLite
  • argparse
  • zipapp
GitHub↗ (opens in a new tab)

Source code shows what a program could do; TraceSieve shows what one run actually did. It traces an execution into a local evidence store, then explains why a function ran, how two scenarios differ, and which functions a scenario never reached.

  • why, diff and gaps commands for call paths, scenario deltas and untested code
  • Built only on the Python standard library and shipped as a single .pyz file
  • Records structure, never arguments, variables or secrets, and runs fully offline
  • Predictable exit codes so it can gate CI pipelines
